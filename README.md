# ColorBlindGame
Проект
Актуальность проекта
В мире более 300 млн человек с дальтонизмом, в России — несколько миллионов.
Большинство существующих приложений — простые копии теста Ишихары без геймификации.
Геймификация повышает мотивацию проходить тест повторно и помогает лучше понять проблему (через симулятор «как видит дальтоник»).
Мои задачи:
Создать новый 2D-проект на Unity и настроить его под Android (Build Settings → Android, IL2CPP, ARM64 и т.д.)
Сделать главную сцену с меню (кнопки «Начать тест», «Симулятор», дисклеймер)
Импортировать 5–10 пластин Ишихары (PNG) и показать первую на экране
Сделать простой уровень: картинка + поле ввода числа + кнопка «Проверить»
Добавить таймер (7–10 секунд) и переход на следующий уровень при ответе
Написать менеджер теста (TestManager.cs) с массивом правильных ответов
Проект полезен для школ, родителей, офтальмологов и разработчиков интерфейсов (тестирование на цветовую доступность).
В 2026 году мобильные приложения для здоровья и образования остаются востребованными, особенно с элементами edutainment.
Цель и задачи
Цель: Разработать Android-приложение для ориентировочного выявления дальтонизма с использованием игровых элементов на базе Unity.
Задачи:
Изучить методику теста Ишихары и типы цветовой слепоты.
Подобрать или адаптировать набор тестовых пластин.
Реализовать игровую механику (уровни, таймер, очки, жизни).
Добавить симулятор дальтонизма (шейдеры для протанопии, дейтеранопии и др.).
Обеспечить сбор и анализ результатов с выводом вероятного типа нарушения.
Собрать APK для Android и протестировать на реальных устройствах.
Реализация
Платформа: Unity (2022 LTS или выше) с Universal Render Pipeline (URP) для мобильной оптимизации.
Язык: C#.
Основные компоненты:
Главное меню с дисклеймером («Это не медицинская диагностика! Обратитесь к врачу»).
Уровни: 10–15 пластин Ишихары (PNG-спрайты из открытых источников, например, 38-плиточный набор).
Геймификация: таймер 7–10 сек, ввод числа через экранные кнопки или поле, очки за скорость/точность, 3 жизни.
Анализ: подсчёт ошибок по группам пластин → вероятность типа дальтонизма (простая таблица правил).
Симулятор: переключение режимов (норма / протанопия / дейтеранопия / тританопия).
Сборка: Android Build Settings → IL2CPP + ARM64, минимум API 28, размер APK ~30–60 МБ.
Дополнительно: звуки, анимации, экспорт результатов (текст или PDF в будущем).
Результаты
Приложение мотивирует пользователей проходить тест полностью благодаря очкам и уровням.
Возможные улучшения: адаптация для детей (животные вместо цифр), интеграция с камерой, статистика в облаке.
1. Экономика проекта
Проект ориентирован на три ключевые ценности:
Комфорт — геймификация делает тест менее стрессовым и скучным (особенно для детей и подростков), превращая медицинскую проверку в увлекательную игру.
Долгая и здоровая жизнь — раннее выявление дальтонизма помогает избежать ошибок в профессиях (водитель, дизайнер, хирург, электрик), где цвет критичен, и повышает безопасность (например, распознавание сигналов светофора).
Расширение сферы влияния — приложение может стать инструментом для школ, клиник, компаний (тестирование сотрудников) и даже государства (профилактика в образовании/медицине), повышая осведомлённость о цветовой доступности.
Монетизация (возможные модели):
базовый тест бесплатно, детальный отчёт + симулятор + статистика по подписке (59–199 руб/мес).
B2B (бизнес): лицензия для компаний (дизайн-студии, автопарки, производители интерфейсов) — корпоративный доступ, брендирование, интеграция в HR-процессы.
B2G (государство/общество): партнёрство с Минздравом, Минпросвещения, Рособрнадзором — внедрение в школы/медосмотры как бесплатный/льготный инструмент профилактики.
2. Тип проекта
Проект сочетает все три типа:
Тип В (общественно полезный) — помогает миллионам людей с дальтонизмом (~8% мужчин), повышает инклюзивность, снижает риски в повседневной жизни и профессиях.
3. Представление проекта (5W)
Что? Что вы собираетесь делать?
Разработка мобильного приложения на Unity для Android, которое проводит тест на дальтонизм (на основе таблиц Ишихары) в игровой форме: уровни с таймером, очками, жизнями, вводом числа/поиска объектов. Дополнительно — симулятор «как видит дальтоник» (шейдеры для протанопии/дейтеранопии/тританопии).
Зачем? Какую пользу даёт продукт?
Пользователь получает быстрый, увлекательный и анонимный ориентировочный тест без визита к врачу. Родители/школы — раннее выявление. Компании — проверка сотрудников. Общество — повышение осведомлённости о цветовой слепоте и доступности интерфейсов. Дисклеймер: «не замена врачу».
Где? Где реализовывать и продавать?
Разработка — локально (мой ПК). Распространение — Google Play (основной), возможно RuStore/AppGallery. Продажа — фокус на русскоязычную аудиторию + страны с высокой распространённостью дальтонизма (Европа, Азия). B2B — прямые продажи компаниям, B2G — через тендеры/партнёрства.
Когда? Сезонность? Ситуация покупки?
Нет яркой сезонности. Пиковые периоды: август–сентябрь (начало учебного года — родители/школы), весна (медосмотры для профессий). Ситуации покупки: подозрение на проблему у ребёнка, профориентация, корпоративный скрининг, интерес к здоровью.
Кто? Целевая аудитория?
B2C: родители детей 6–16 лет (основная), подростки/молодёжь 16–25, взрослые 25–45 (самопроверка).
B2B: HR-отделы компаний (транспорт, дизайн, промышленность), оптика/офтальмологические клиники.
B2G: школы, поликлиники, центры профориентации.
